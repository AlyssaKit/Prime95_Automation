\# AI Use



I used ChatGPT as a development and debugging assistant throughout this

project.



AI assistance included:



\- discussing the overall Python orchestration design;

\- helping implement and debug Prime95 process control;

\- helping interpret Prime95 configuration and runtime output;

\- assisting with HWiNFO Shared Memory integration and telemetry parsing;

\- debugging FFT worker tracking and full-cycle detection;

\- reviewing runtime results and identifying problems with earlier

&#x20; implementation approaches;

\- assisting with documentation and technical explanations.



AI-generated suggestions were not treated as automatically correct.

Changes were tested against the actual Prime95 and HWiNFO environment,

and the implementation was revised when observed runtime behavior

differed from assumptions or proposed solutions.



I performed the system configuration, executed the diagnostic and full

test runs, reviewed the resulting telemetry and Prime95 output, and

validated the final behavior of the program.



The final full test completed successfully with runtime FFT validation

passing and the program automatically detecting completion of a

representative FFT cycle.



I did not use an AGENTS.md instruction file during development.

My AI-assisted development was performed through conversational

interactions with ChatGPT, so there is no original/raw AGENTS.md

file to include.
